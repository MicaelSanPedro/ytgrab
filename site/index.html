Como instalar

1

Baixe o instalador

Escolha Windows, macOS ou Linux acima e baixe o instalador.

2

Instale e abra

Execute o instalador. O YTGrab abre automaticamente ao final.

3

Pré-requisitos: yt-dlp + ffmpeg

O app precisa do yt-dlp e ffmpeg instalados. Instale com:

# Windows (com winget)
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
# macOS (com Homebrew)
brew install yt-dlp ffmpeg
# Linux (Ubuntu/Debian)
sudo apt install ffmpeg
pip install yt-dlp
4

Cole a URL e baixe!

Cole qualquer link do YouTube, escolha formato e qualidade, e clique em Baixar.
